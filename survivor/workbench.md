Coding rules- GDScript: type `:=` explicitly (Variant `:=` is a hard error); never `:=` on expressions rooted at untyped refs (`world`/`Game`/`DB`/etc. — e.g. `world.fx.debug_stats()` killed boot 2026-10-14, fix is `var fx: Dictionary = ...`), use an explicit type or plain `=`; every `p[...]` read must exist in the `.tres` base keys (checkers enforce). `tools/gdscript_lint.py` owns this rule (GDS101 direct Variant `:=` = error, GDS102 propagated = review, GDS201 unused parameter = review) and is imported by `check_project.py` + `check_black_market.py`, so never re-implement it there.- Art strips: square-cell horizontal strips, cell derived in `AbilityArt.frame_region`; validator accepts Wx32/Wx64 (ability art) and 48/64px cells (enemy strips, e.g. hellfire 4x64px). Currency seal strip (`art/pickups/seal.png` 12x24x28, non-square) is exempt: UI `CoinIcon` animates all 12 frames, world coins draw static frame 0. New art PNGs gain committed `.import` sidecars on first Godot import. PNG size changes reimport on mtime.- Whitespace: a file keeps the indent style and line ending it has at git HEAD (tabs in some files, 4 spaces in others, CRLF in a few). There is no per-file list. `tools/check_text.py` enforces it plus mojibake, mixed tabs/spaces, mixed EOL, OVER-INDENT and BAD-STEP; `--fix` repairs pure whitespace / mixed line endings.
